# Эмулятор оболочки ОС (Вариант 19)

## Общее описание
Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS).

## Функции и настройки
- CLI-интерфейс
- Команды: ls, cd, whoami, uname, clear, rm, help, exit
- Загрузка VFS из ZIP-архива
- Параметры командной строки: путь к VFS, путь к стартовому скрипту

## Сборка и запуск
python src/main.py
